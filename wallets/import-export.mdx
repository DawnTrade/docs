Both happen in the **wallet manager**, a mini app inside Telegram. Send `/wallets` and tap **🗝 Import** or **🔑 Export** under the list.

<Warning>
  A private key is complete control of a wallet. Type one only into the import form inside the official Dawn app. Never send a key to support, to a group, to another person, or into any chat — including this one.
</Warning>

## Import a wallet

<Steps>
  <Step title="Open the importer">
    `/wallets` → **🗝 Import**.
  </Step>

  <Step title="Pick the profile">
    It needs a free slot: each profile holds **5 wallets**. Add a label if you want one.
  </Step>

  <Step title="Paste the key">
    A **Solana** key, an **EVM** key, or **both** to pair them into one wallet. Import one side only and Dawn makes a fresh address for the other.
  </Step>

  <Step title="Confirm">
    The imported wallet becomes the one in use in that profile.
  </Step>
</Steps>

<Info>
  Your key is encrypted on your own device before it's sent anywhere, and Dawn never sees it in readable form.
</Info>

## Export a private key

<Steps>
  <Step title="Open the wallet manager">
    `/wallets` → **🔑 Export**.
  </Step>

  <Step title="Pick the wallet">
    Check the label and address. For a wallet in another profile, switch profile in Telegram and reopen the app.
  </Step>

  <Step title="Reveal and store it">
    With [2FA](/wallets/two-factor) on, Privy asks for it first. Save the key somewhere only you can reach: a password manager, not a screenshot or a chat.
  </Step>
</Steps>

Exporting changes nothing about the wallet: it keeps trading in Dawn as before. Each wallet has its own key, not a shared seed phrase, so exporting one reveals no other.

## If the app opens on the wrong account

The app uses your Telegram account. If it shows wallets you don't recognise, reopen it from the Telegram account you use with Dawn. If a wallet is missing, check which profile you're in.
