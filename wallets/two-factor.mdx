Once it's on, [approving a send or withdrawal](/funds/withdraw#approve-it-in-the-wallet-app) and [exporting a private key](/wallets/import-export#export-a-private-key) ask for your code or passkey first. Trading never does: buys, sells, orders, TP/SL and [copytrade](/copytrade/overview) work as before.

## Set it up

<Steps>
  <Step title="Open the 2FA screen">
    Send `/wallets`, tap **🔐 2FA**, then **Set up**. [Privy](https://privy.io), which secures your wallets, walks you through it.
  </Step>

  <Step title="Pick a method">
    | Method | Notes |
    | --- | --- |
    | **Authenticator** | A code from an authenticator app. Works inside Telegram, so it's the easiest choice. |
    | **Passkey** | Face, fingerprint or device PIN. Needs a browser tab, so it can't be set up inside the Telegram app. |
    | **SMS** | A code sent to your phone. |
  </Step>
</Steps>

To add or remove a method later, open **🔐 2FA** again and tap **Manage**.

<Warning>
  Keep access to your second factor. Set up the backup your authenticator app or phone number offers now, not after a phone is lost.
</Warning>

See also [Security](/wallets/security).
