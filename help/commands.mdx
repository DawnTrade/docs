The fastest way to a coin isn't a command: paste its contract address and it opens with buy buttons ready.

## In your chat with Dawn

| Command | Opens |
| --- | --- |
| `/start` or `/home` | The main menu |
| `/portfolio` or `/positions` | The coins you hold and how they are doing |
| `/trending` | The top coins right now |
| `/search` | Coins matching a phrase: `/search pepe` |
| `/activity` or `/history` | Past trades and their profit or loss |
| `/orders` or `/limitorders` | Your open [orders](/orders/manage): limits, ladders, DCA plans, TWAPs and TP/SL |
| `/limit` | A limit order: `/limit <address>`, or [the whole order in one message](/orders/limit#place-one-with-a-command) |
| `/alerts` | Your [trader alerts](/alerts/traders) and [price alerts](/alerts/price) |
| `/tracker` | Your [trader alerts](/alerts/traders) |
| `/ladder` | A ladder across a market-cap range: `/ladder <address>` |
| `/dca` | A scheduled buy plan: `/dca <address>` |
| `/copytrade` | Your [copytrade](/copytrade/overview) tasks |
| `/deposit` | Deposit addresses for every chain |
| `/withdraw` | Withdraw to an address, normally or [privately](/funds/withdraw#private-withdrawals) |
| `/send` | [Send](/funds/withdraw) USDC, a chain's coin or any token you hold |
| `/wallets` or `/wallet` | Your wallets, balances and addresses |
| `/rewards` | Your [cashback and referrals](/rewards/overview), and claiming what you earned |
| `/settings` | Slippage, auto buy, guardrails, auto sell |
| `/feedback` | [Send the team an idea or a problem](/help/support#send-feedback) |
| `/support` | A chat with [the Dawn team](/help/support) |
| `/help` | What the bot does |

<Tip>
  Tap the **/** button beside the message box for the command list without leaving the chat.
</Tip>

## In a group

For admins of a group [Dawn has been added to](/social/groups).

| Command | What it does |
| --- | --- |
| `/setup` | Register the group, or take it over as an admin |
| `/amounts 5 10 25 50` | Set the card's buy buttons, one to four amounts |
| `/compact on` | Shorten the card. `/compact off` restores it |

## Things that are not commands

| Send | And you get |
| --- | --- |
| A wallet address | What that wallet has been trading, with buttons to [copy it](/copytrade/overview) or [get alerts](/alerts/traders) on it |
| A fomo.family profile link | That trader's [fomo card](/copytrade/find-trader#look-up-a-fomo-trader) |
| `bnb 0x…`, `base 0x…`, `hype 0x…` | The coin on the chain you named: [every prefix](/chains#naming-the-chain-yourself) |
| `$PEPE` | A [search](/trading/trending) for coins by that ticker |
