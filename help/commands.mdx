The fastest thing in Dawn is not a command. **Paste a contract address** and the coin opens with buy buttons ready.

For everything else:

## In your chat with Dawn

| Command | Opens |
| --- | --- |
| `/start` | The main menu |
| `/portfolio` | The coins you hold and how they are doing |
| `/trending` | The top coins right now, by chain and filter |
| `/search` | Coins matching a phrase — `/search pepe`. Bare, it opens the same screener |
| `/activity` | Past trades and their profit or loss |
| `/orders` | Open limit orders, ladders, DCA plans, TWAPs and TP/SL — see [Managing orders](/orders/manage) |
| `/limit` | A limit order — `/limit <address>`, or [a whole order in one message](/orders/limit#place-one-with-a-command) |
| `/alerts` | Your [price alerts](/alerts/price) — the same as **🔔 Price Alerts** on the home screen |
| `/ladder` | A ladder across a market-cap range — `/ladder <address>` |
| `/dca` | A scheduled buy plan — `/dca <address>` |
| `/copytrade` | Your copytrade tasks — [follow a wallet or a fomo trader](/copytrade/overview) |
| `/deposit` | Deposit addresses for every chain |
| `/withdraw` | Send money out to an address |
| `/wallets` | Your wallets, balances and addresses |
| `/rewards` | Your cashback and referrals, and claiming what you earned — see [Rewards](/rewards/overview) |
| `/settings` | Slippage, auto buy, guardrails, auto sell |
| `/feedback` | Send the team an idea or a problem — see [Send feedback](/help/support#send-feedback) |
| `/help` | What the bot does |

[Trader alerts](/alerts/traders) open from **🔔 Tracker** on the home screen, or `/tracker`.

### Aliases

The same screens answer to more than one name.

| Also works | Same as |
| --- | --- |
| `/home` | `/start` |
| `/positions` | `/portfolio` |
| `/history` | `/activity` |
| `/limitorders` | `/orders` |
| `/wallet` | `/wallets` |
| `/send` | `/withdraw` |

## In a group

For admins of a group [Dawn has been added to](/social/groups).

| Command | What it does |
| --- | --- |
| `/setup` | Register the group, or take it over as an admin |
| `/amounts 5 10 25 50` | Set the card's buy buttons — one to four amounts |
| `/compact on` | Shorten the card. `/compact off` restores it |

## Things that are not commands

| Type this | And you get |
| --- | --- |
| A contract address | That coin's panel |
| A wallet address | What that wallet has been trading, with buttons to [copy it](/copytrade/overview) or [get alerts](/alerts/traders) on it — Dawn can tell a wallet from a coin |
| A fomo.family profile link | That trader's [fomo card](/copytrade/find-trader#look-up-a-fomo-trader) |
| `bnb 0x…`, `base 0x…`, `hype 0x…` | The coin on the chain you named — [every prefix](/chains#naming-the-chain-yourself) |
| `$PEPE` | A [search](/trading/trending) for coins by that ticker |

<Note>
  Dawn's menu of commands is also in Telegram itself — tap the **/** button beside the message box for the list without leaving the chat.
</Note>
