Open a task from **Manage** on your [task list](/copytrade/overview#your-tasks). The performance on its page counts only the coins this task bought.

Those coins are ordinary positions: they show in your [portfolio](/trading/portfolio), and you can sell them or set a [TP/SL](/orders/tp-sl) on them yourself. They stay yours if you pause or delete the task.

## Min and max per buy

A task sized by **📊 % of the Leader's Buy** or **⚖️ Portfolio Weighted** can keep each copy between a min and a max. Set them in the last step of **💵 Edit Size**:

- **Max per buy**: a bigger copy is cut down to it.
- **Min per buy**: a smaller copy is raised to it.

A task that buys a fixed amount has no min.

## Settings

Each task has its own trading settings. **Default** means it uses your [profile's](/settings/overview) setting; change it here and only this task changes.

| Setting | What it does |
| --- | --- |
| 🔁 **Mirror Sells** | On: when the leader sells, you sell the same share. Off: you only copy their buys. |
| 🤝 **Hold if Down** | With Mirror Sells on, you sell with the leader only while you're in profit. If you're down, you keep the position. Pair it with a stop loss in **📈 Auto Sell**. |
| **Limit Order On Miss** | Sets a limit buy at the leader's entry on every [missed copy](/copytrade/overview#missed-copies). Off by default. |
| 🎯 **Slippage** | How far above the leader's entry price a copy may buy. **15%** unless you change it; **Off** copies at any price. |
| 🛡 **MEV** | See [MEV protection](/trading/execution#mev-protection). |
| ⛽️ **Gas** | See [Gas preset](/trading/execution#gas-preset). |
| 📈 **Auto Sell** | A stop loss and take profit on every buy the task makes. |
| 🌐 **Chains** | fomo tasks only. See [Chains](#chains). |

## Filters

Filters decide which of the leader's buys the task copies. A buy that fails a filter, or a coin with no data for it yet, is skipped. Sells are never filtered.

| Filter | Skips a buy when |
| --- | --- |
| 🌱 **First Buys Only** | It isn't the leader's first buy of the coin (an add or a re-entry) |
| 🥇 **First Buy Wins** | You already hold the coin, so two traders buying it give you one position |
| 🎯 **Buy Min** | The leader spent less than this |
| 💎 **MC Min** | The coin's market cap is below this |
| 💎 **MC Max** | The coin's market cap is above this |
| 💧 **Liq Min** | The pool holds less than this |
| 📊 **Vol 24h** | Less than this traded in the last day |
| 👥 **Holders** | The coin has fewer holders than this |
| 🐋 **Top 10** | The top ten wallets hold more than this share |
| ⏱ **Age Min** | The coin is younger than this |

<Tip>
  **⏱ Age Min** and **💧 Liq Min** keep a task out of brand-new and thin coins without stopping it copying real moves.
</Tip>

## Chains

A task on a fomo trader copies them on every chain they trade. Switch chains off or on under **🌐 Chains** in the task's settings. Switching one off stops new copies there; positions you already hold stay.

A task made from an address keeps the chains you picked when you created it.

## Wallet

**💳 Change Wallet** moves the task to another of your wallets, in any profile. Coins already bought stay in the wallet that bought them.

## Activity

**🕘 Activity** lists everything the task has done, newest first, including copies it skipped or couldn't place and why. The same button on the task list shows every task together.

## Sharing a task

**🔗 Share Task** sends someone a link to this trader. Whoever taps it starts their own copytrade setup with the trader already filled in.
