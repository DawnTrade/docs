Every account starts with one code, and you can hold up to **10**. Each has its own link and its own referral count: put one in your group, one on X, one on a single post, and see which brings people in. All codes pay into the same earnings.

Open **🎁 Rewards → 👥 Referrals → 🔗 Manage Codes**.

## Renaming and deleting

<Warning>
  **Renaming or deleting a code breaks every link that uses it.** If a link is already out there, create a new code instead.
</Warning>

Either way, the code's referrals and earnings stay yours.

Your **main code** can be renamed once a day, but not deleted. It's the one on your [share cards](/social/share-links) and [group posts](/social/groups).
